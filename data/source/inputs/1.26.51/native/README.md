# Native Bedrock measurements

Selected CC0-1.0 data from didntpot/bedrock-data, commit
bb896a46ba856c58383e3cfb962a38c45a0dea78, release/1.26.51 (protocol 2193).
The original files are retained byte for byte. Their SHA-256 digests are recorded
in the parent source lock. Vendoring these inputs makes regeneration work without
access to the upstream repository. See LICENSE for the upstream licence.

The block property table supplies the complete identifier domain; the tag map
contains tagged blocks. State properties use palette ordinals. Consumers check
identities, counts and required fields before joining these files. The snapshot
does not supply complete native mining algorithms or dynamic collision shapes.
